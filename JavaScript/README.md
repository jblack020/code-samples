# JavaScript Code Samples
When I was in high school and early on in college, I built Collage, a Chrome extension designed to make research easier for high school and college debaters. This project is about as old as my coding experience (hence why it uses JQuery and is a monofile), but I thought it'd be a good pre-AI era inclusion to show my proficiency in JavaScript.

**script.js**
Powers the card library: saving, searching, grouping, and tagging cards, plus importing and exporting a library.

**appscript.js**
From Cabot Room Book, a Google Calendar add-on I built that finds and books open study rooms in Harvard's Cabot Library. This Google Apps Script takes a calendar event, asks my Python server (see the Python folder) which rooms are free for that time, and shows them in a sidebar with one-click booking.

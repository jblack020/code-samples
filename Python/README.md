# Python Code Samples
These code samples come from four separate projects; two from my time as a research assistant, one from a final project in one of my classes on data science, and one from Cabot Room Book, a tool I built for booking study rooms. I've been working with Python for a long time, but I feel given their context, these are the most applicable samples of my work!

**crop-prices**
From my work under Dr. Ada González-Torres, who was a visiting fellow at the Weatherhead Center at Harvard. I was tasked with fetching crop prices from three different sources (FAO, WBK, and WFP), cleaning and merging them, and then mapping them to the chiefdom/district they belonged to. More documentation of the process can be found in the files.

**main.ipynb**
A group final project (team of 4) for CS 1090A that utilizes a variety of machine learning methods to attempt to predict which Supreme Court justice authored a given opinion based on the style of the text. I wrote the code found in this notebook.

**map.py**
Part of my work under Dr. Eswar Prasad at the Brookings Institution was creating a process by which we map securities to their corporate issuers. This script does just that and utilizes a cache to keep things efficient. 

**cabot-room-booker**
The backend for Cabot Room Book (the Google Calendar add-on is in the JavaScript folder). It uses Selenium to scrape Cabot Library's booking site for rooms that are free during a calendar event, works out how long each room stays open, and books the room by filling out the reservation form.

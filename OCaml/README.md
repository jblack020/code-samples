# OCaml Code Samples
This code sample is from my final project in CS51, officially titled "Abstraction and Design in Computation" (a fancy way of saying that it is a more advanced programming course). The course is taught in OCaml because it covers functional, imperative, and OOP, and OCaml implements all three. The project, which was building an interpreter for MiniML (a small subset of OCaml) and extending the language with new features, is proof of my proficiency in the language. Although OCaml is not widely used (with the exception of Jane Street), the programming concepts it taught were invaluable!

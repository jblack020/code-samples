# C++ Code Samples
These code samples are from my assignments in CS61 (Systems Programming) with Eddie Kohler, which I took as a sophomore at Harvard.

**kernel.cc**
A kernel for WeensyOS, a small teaching operating system, written in C++. It handles process memory allocation, scheduling, system calls, etc. *(some of the more important things a real kernel does)*. It's been a while since I've looked at page tables, but I'm still comfortable in C++ if we ever need fast execution or low-level memory management.

**m61.cc & sh61.cc**
A debugging memory allocator and a Unix shell, respectively. Included for completeness.
